服务器离不开ssh及sftp，本人作为苹果用户一直使用默认的终端已经10几年了，作为ssh也足够优秀，但也有两个痛点：

1同一个ip换了网卡后，密钥会冲突，必须清空旧密钥再连接：

```
ssh-keygen -R 服务器地址
```

对虚拟机玩家这是非常高频的操作，经常需要测试重装软路由或换sriov网卡，每次都要操作一次，这还是最麻烦，有时候需要上传文件就必须使用sftp。

2没有sftp非常不方便，用自带的finder访问不同的服务器也很麻烦，使用过一段时间的第3方sftp，体验真的差，例如：FileZilla和FinalShell只能说能不用尽量不想使用。

无意中发现了这款ui非常漂亮的ssh及sftp工具：**Termiuis**（源自拉丁语：白蚁）

![](Pasted%20image%2020261024071613.png)

抱着白老鼠的心态下载安装，真的惊艳到我了，登陆后居然可以自动扫描局域网下所有支持ssh的ip地址，支持ipv6，连接非常简单，直接点击后输出用户名密码，一般的ssh工具需要先配置好才能连接，多任务切换非常方便，例如在根目录检查网卡，另外开一个任务进入docker检查网络，

![](Pasted%20image%2020261024071406.png)

使用自动完成功能或侧面板中的“代码片段”部分，在终端中 访问您**保存的命令。无论哪种方式，您都可以比从内部文档中复制粘贴命令更快地运行已保存的命令。并且它还适用于分屏视图中的广播。**


**在多台主机上**运行命令。例如，当您需要更新整个服务器组时，可以运行sudo apt-get update && apt-get upgrade。从“代码片段”屏幕中选择一个命令，然后在选定的主机和组上运行它。您将看到每次执行的状态，以便立即进入会话进行故障排除。

**专业提示：**将目标保存到代码片段，只需单击一下即可在选定的主机上运行命令。

首先添加命令，然后将它们整理成**代码片段包，**以便于导航。您甚至可以使用**AI**生成代码片段。描述操作，然后点击魔术棒按钮即可获取执行该操作的命令。

**连接启动时**

运行命令：cd 到指定目录，或连接后激活工作环境。前往主机并将代码片段保存为启动命令。
